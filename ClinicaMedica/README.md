# Clínica Médica — Java Swing MVC

Projeto Eclipse Java simples, sem dependências externas, com cadastro de pacientes.

## Abrir no Eclipse 2026-09
1. Descompacte o ZIP.
2. No Eclipse: **File > Import > General > Existing Projects into Workspace**.
3. Em **Select root directory**, selecione a pasta `ClinicaMedica` descompactada.
4. Marque o projeto e clique em **Finish**.
5. Abra `src/br/com/clinica/app/Main.java` e escolha **Run As > Java Application**.

Requer JDK 17 ou superior (recomendado 21).

## Funcionalidades
Cadastrar, listar, selecionar, atualizar e excluir pacientes.

## Atenção
Os dados são mantidos em memória e perdidos ao fechar o aplicativo.
Validação de CPF, persistência, autenticação e controles LGPD ficam para versões futuras.
Use somente dados fictícios nesta versão.
